# SpanGuard demo

From classified LiDAR to span-level clearance risk, in 3D.

- **Live viewer:** https://adityagis.github.io/spanguard-demo/
- **Handbook:** https://adityagis.github.io/spanguard-demo/handbook/ ([PDF](handbook/SpanGuard-Handbook.pdf))

This repository holds only the built website: the network viewer with three processed demo zones of real drone LiDAR (GridNet-HD, CC-BY-4.0, HEIG-VD). Wire curves, weather cases, clearance, ratings and findings were computed by the SpanGuard pipeline; the live what-if runs in the browser.

Built by Aditya Kumar Jha with Claude (Anthropic) through Claude Code.
